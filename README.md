# Hero Dirt Forecast — Connecticut

Experimental trail-condition forecasting for Connecticut using observed precipitation, satellite soil moisture, weather forecasts, terrain, soils, vegetation, and a three-layer trail-surface hydrology model.

## Status

**v2 Beta**

The current model includes Penman-style atmospheric trail-surface drying driven by temperature, humidity, wind, solar radiation, cloud cover, terrain, and vegetation.

This is an experimental forecasting system. Conditions can vary substantially along individual trails and are not direct measurements of trail tread conditions.
